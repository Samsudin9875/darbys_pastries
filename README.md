# Darby's Pastries

React + Vite frontend and Express production server for Darby's Pastries.

## Run locally

```bash
npm install
npm run dev
npm run dev:server
```

- Frontend: `http://localhost:5173`
- API health check: `http://localhost:3000/api/health`

## Production

```bash
npm ci
npm run build
npm start
```

The Express server serves only `client/dist` in production. Set these server environment variables in the hosting platform:

```env
NODE_ENV=production
PORT=3000
CLIENT_ORIGIN=https://your-domain.example
```

Never commit API secrets. Cloudinary upload credentials belong only in server-side environment variables.

## Current storefront migration

The existing storefront source of truth is `client/legacy`. The predev and prebuild scripts extract its embedded images and sync its HTML, CSS, and JavaScript into `client/public/legacy`, which Vite and the production server serve. Edit the source files in `client/legacy`, not their generated public copies. Do not edit `client/dist`; it is generated by `npm run build`.
